# Presentations

Slides from my talks, built with [reveal.js](https://revealjs.com) and published with GitHub Pages at [fsdias.github.io/presentations](https://fsdias.github.io/presentations/).

Each folder holds one talk and has its own README describing it.

| Folder | Talk | Event | Slides |
|---|---|---|---|
| [`speco21/`](speco21) | Analysing the distance decay of community similarity in river networks using Bayesian methods (in Portuguese) | 20.º Encontro Nacional de Ecologia (SPECO), November 2021 | [view](https://fsdias.github.io/presentations/speco21/) |
| [`bigdata/`](bigdata) | How to manage and process big datasets in R: an example with eBird data | Journal Club, March 2023 | [view](https://fsdias.github.io/presentations/bigdata/) |

## Viewing the slides

Open the links above in a browser. Press `→`/`Space` to advance, `Esc` for the slide overview, `S` for speaker notes and `F` for full screen. To print or save as PDF, add `?print-pdf` to the URL and print from Chrome/Chromium.

To view the slides offline, clone the repository and open `<folder>/index.html` in a browser.
